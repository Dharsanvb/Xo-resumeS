# XO-Resume 🚀  
### AI-Powered Resume Builder with Live Share & Smart Enhancements

XO-Resume is a modern **AI-powered resume builder** built using the **MERN stack**, designed to help users create professional resumes effortlessly with real-time updates, AI-enhanced content, and a clean, intuitive UI/UX.

---

## 🌟 Key Highlights

- ✨ AI-enhanced resume content (Professional Summary & Experience)
- 🖼️ Smart image processing (Face focus & background removal)
- 🔗 Live, shareable resume links with auto-updates
- 📄 One-click PDF download
- 🔐 Public / Private resume visibility control
- ⚡ Fast, responsive, and user-friendly interface

---

## 🎯 Why XO-Resume?

Traditional resume building is:
- Time-consuming  
- Difficult for non-native English speakers  
- Static and hard to update  

**XO-Resume solves this by combining AI + modern UX**, allowing users to focus on their career, not formatting.

---

## 🧭 User Experience Flow

1. **Landing Page**
   - Clean hero section
   - Clear call-to-action
   - Minimal footer with essential links

2. **Dashboard**
   - Centralized resume management
   - “Create Resume” button for guided creation

3. **Resume Builder Sections**
   - Personal Information
   - Professional Summary (AI-powered)
   - Experience (AI-powered)
   - Education
   - Skills

4. **Publish & Share**
   - Toggle resume visibility (Public / Private)
   - Generate live resume link
   - Download resume as PDF

---

## 🖼️ Personal Info & Image Intelligence

- Image upload powered by **ImageKit**
- Automatic **face center focus**
- Optional **background removal toggle**
- Optimized images for professional resumes

This ensures every resume looks clean and polished without extra effort.

---

## 🤖 AI-Powered Enhancements

XO-Resume integrates **Gemini AI API** to improve resume content:

### ✍️ Professional Summary
- User writes a basic summary
- Click **“Enhance with AI”**
- AI rewrites it into a professional, ATS-friendly version

### 💼 Experience Section
- Enhances job descriptions
- Improves clarity, tone, and impact
- Maintains user intent while upgrading language

---

## 🔗 Live Resume Sharing

- Set resume as **Public**
- Get a **live online link**
- Any future edits automatically reflect on the same link
- Perfect for recruiters and instant sharing

> No re-upload. No new links. Always updated.

---

## 📄 PDF Export

- Download resumes as **offline PDF**
- Maintains design consistency
- Ideal for email submissions and uploads
